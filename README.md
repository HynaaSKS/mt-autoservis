# MT AUTOSERVIS – web (React + JavaScript)

Obyčejný React projekt vytvořený nástrojem **Vite**.

## Spuštění (VS Code)
1. Nainstaluj Node.js LTS z https://nodejs.org.
2. Ve VS Code: File → Open Folder → vyber složku `mt-autoservis`.
3. Terminal → New Terminal a napiš:
   
   npm install
   npm run dev
   
4. Otevři adresu, kterou terminál vypíše
   Po uložení souboru (Cmd+S) se stránka sama obnoví.
